Guide

How to use CityScout.

The Globe

Drag to rotate, scroll to zoom, double-click to reset. Click a country name badge to enter country view. Click a city to open the flat map.

Use the Explore Cities panel (bottom-left) to jump straight to any city by selecting country then city from the dropdowns.

Candidate Mode

Candidate mode activates automatically when you navigate to a city. The toolbar across the top lets you filter candidates by status or search by name.

Click any coloured dot on the map to open the review sidebar on the right. From there you can:

  • Approve for Inclusion — moves candidate toward publishing
  • Needs Visit — flags the venue for an in-person check
  • Needs Review — pauses the candidate for further research
  • Reject — removes the candidate from consideration (with reason)
  • Edit Details — update name, description, category, tier, coordinates, tags, and more via the edit form
  • Log Observation — record a first-hand or trusted review directly against the candidate

Adding Venues

Use the toolbar buttons when in a city map view:

  • ↑ Import CSV — bulk upload venues using the CityScout schema. Download the template first to ensure column alignment with the Lovable database.
  • + Add Venue — add a single venue via the form. City and country are pre-filled from the map you're viewing.

All imported venues land as Stub status and must be reviewed before they can be published.

CSV Schema

The import CSV must match the Lovable/Supabase establishments table column order exactly. Download the template from the Import CSV panel to get the correct headers. Key required fields: name, city, country. All other fields are optional.
